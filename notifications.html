why this matters
In the actual testing session, all four of these events happened for real — including a real-money trade execution and a real-money strategy hitting an error — and none produced any signal. The only way to know was to manually reopen the strategy page. A notification layer doesn't need new data: every event here is something Nabu's backend already tracks and displays somewhere — the gap is that none of it reaches the user proactively.
